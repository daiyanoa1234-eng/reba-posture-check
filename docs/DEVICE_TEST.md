# 実機確認の手順（iPhone Safari / Android Chrome）

**現時点では、すべての項目が実機で未検証です。** PC（macOS 上の Chromium 系ブラウザ）での確認結果は README の「検証状況」を参照してください。
確認した項目は、下の記録表に端末名・OS・ブラウザの版と結果を書き込んでください。

## 準備

1. 公開 URL を開く: https://daiyanoa1234-eng.github.io/reba-posture-check/
   （LAN 内で開発版を試す場合は README「起動方法」の `npm run dev:https` を参照）
2. 確認用の動画を用意する
   - A: 作業者1人・全身・真横・10〜20秒（基本ケース）
   - B: 20秒を超える動画（区間選択の確認）
   - C: 複数人が映る動画
   - D: 足首が画面外に出る動画
   - E: iPhone の HEVC（高効率）で撮影した動画（Android で読めるか）
   - F: 人物が映っていない動画

## 確認項目

### 1. 初回表示・オフライン

- [ ] 初回アクセス後、ホームの「オフラインで利用できる状態です」が表示される（数十秒かかる場合あり。初回は約 21MB を取得）
- [ ] 解析モデルの状態が「準備完了」になる
- [ ] ホーム画面に追加できる（iPhone: 共有 → ホーム画面に追加／Android: メニュー → アプリをインストール）
- [ ] 機内モードにしてホーム画面のアイコンから起動し、端末内の動画で解析まで完了する
- [ ] 機内モードで「標準モデル」を選んだ場合（事前に詳細設定で取得していなければ）読み込み失敗の案内が出て、画面が固まらない

### 2. 撮影

- [ ] 「撮影する」でカメラ使用の許可を求められ、背面カメラのプレビューが出る
- [ ] 録画開始後、残り秒数が表示され **20秒で自動停止** する
- [ ] 停止ボタンで途中停止できる
- [ ] 停止後、自動で解析が始まる
- [ ] カメラを拒否した場合、案内と「端末のカメラで撮影」ボタンが表示される

### 3. 動画の選択

- [ ] 写真ライブラリ／ファイルから動画を選べる（A）
- [ ] 20秒を超える動画で区間選択が表示され、開始位置・長さの変更と区間再生ができる（B）
- [ ] 読み込めない形式で、分かりやすい案内が表示される（E・破損ファイル）

### 4. 解析

- [ ] 進捗（n / 全体）、経過時間、直近フレームの骨格が表示される
- [ ] 解析中もスクロール・キャンセルボタンが反応する
- [ ] キャンセルで準備画面に戻り、再開できる
- [ ] 結果画面に解析時間（モデル準備・1フレームあたりの読込/推定時間）が表示される → 記録表に記入
- [ ] 人物未検出（F）・複数人（C）・全身外（D）で注意が表示され、アプリが止まらない

### 4-2. 精度設定

- [ ] 準備画面で「速度優先／高精度／最高精度」を選べ、初期値がスマホでは「高精度」、PC では「最高精度」になっている
- [ ] 各設定で解析が完了する。解析時間を記録表に記入（特に「最高精度」がスマホで実用的な時間か）
- [ ] 機内モードで「最高精度」を選ぶと（事前取得していなければ）読み込み失敗の案内が出る。詳細設定の「オフライン用に取得」後は機内モードでも使える

### 4-3. 関節点の調整

- [ ] 「関節を調整」→ 点をタップで選択 → ドラッグで動かせる。指の上に拡大鏡が出る
- [ ] 点を選んだ後、画像の別の場所をドラッグしても選んだ点が動く（指で点が隠れない）
- [ ] ＋で拡大すると選んだ点が画面中央に来る。選択を解除すると拡大画像をドラッグで移動できる
- [ ] ◀▲▼▶で1px ずつ動く、「元に戻す」「自動推定に戻す」「すべて自動推定に戻す」が効く
- [ ] 調整すると角度表・3D骨格・スコアが変わり、姿勢確認のチェックが外れる
- [ ] 結果画面と CSV に調整した関節名・調整前後の角度が出る

### 4-4. 場面ごとの入力

- [ ] 手動項目を入力後、別の候補に切り替えて戻っても入力が残っている
- [ ] 別の場面で「重量・把持・活動をコピー」が使える
- [ ] 評価側（左右）を切り替えても、それぞれの側の入力が残っている

### 5. 場面選択・表示

- [ ] 候補が最大3つ表示され、タップで切り替わる
- [ ] グラフ・スライダー・◀▶で別のフレームを選べる
- [ ] 骨格線・関節点・角度ラベルが動画フレームに重なって表示される（左=橙、右=青）
- [ ] 「3D骨格を表示」で3D骨格が表示され、指で回転・ピンチで拡大縮小できる。フレームを変えると3Dも同じ時刻に変わる
- [ ] 評価側（左/右）を切り替えると、上腕・肘・手首の角度表示が変わる

### 6. 手動入力・結果

- [ ] 大きなボタンで全項目を入力できる（手袋着用でも押せるか）
- [ ] 未確認が残る間は「仮評価（範囲）」、全項目＋姿勢確認で「確定」になる
- [ ] 結果画像に骨格・点数・リスク区分が描かれ、顔にモザイクがかかる（OFF にも切り替え可）
- [ ] 「確定して端末に保存」→「保存した評価」に表示される。アプリを閉じて再度開いても残っている
- [ ] 画像の書き出し（iPhone: 共有シート → 画像を保存／Android: 共有またはダウンロード）
- [ ] CSV の書き出しと、Excel 等で文字化けせずに開けること
- [ ] 保存した評価を削除できる

### 6-2. PC（参考: Windows/Mac の Chrome・Edge・Safari）

- [ ] 幅 1024px 以上で評価ワークスペース（左: 解析、右: スコアとチェックリスト）になり、幅 1500px 以上で 3D と角度表が中央列に並ぶ
- [ ] ←/→ でフレーム移動、Ctrl/⌘+Z で関節調整を元に戻せる。調整モード中は矢印キーで選択中の点が1px（Shift で10px）動く

### 7. 表示・操作性

- [ ] 屋外（直射日光下）で文字・ボタンが読める
- [ ] 縦画面で横スクロールが発生しない
- [ ] Android の戻るボタンでアプリ内の前の画面に戻る
