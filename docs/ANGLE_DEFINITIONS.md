# 角度の定義と計算方法

実装: `src/lib/angles/angles.ts`（テスト: `src/lib/angles/angles.test.ts`）

## 前提

- 入力は MediaPipe Pose Landmarker の **world landmarks（推定3次元座標）**。単位 m、原点は左右股関節の中点。
  - x = 画像の右方向、y = 画像の下方向、z = カメラから遠ざかる方向。
  - 奥行き（z）を含め **画像1枚からの推定値** であり、実際の関節位置を測定したものではない。
- **鉛直上向き U = (0, −1, 0)**（画像の上方向）とみなす。スマホを傾けずに構えて撮影していることが前提。カメラが傾くと、その分だけ体幹などの角度がずれる。
- 左右は **作業者本人から見た左右**（MediaPipe の定義）。
- 各フレームを独立に推定する（時間方向の平滑化なし）。採点には選んだ1フレームの値だけを使う。
- 角度を出す前に、必要な関節点が画面内にあり visibility がしきい値（初期値 0.5）以上かを確認し、満たさない部位は **角度を出さない（—）**。visibility は「映っている見込み」であり、角度の精度を保証する値ではない。

## 基準となる座標軸

| 記号 | 定義 |
|---|---|
| Lp（骨盤の左方向） | 右股関節→左股関節 を水平面へ投影して正規化 |
| Fp（骨盤基準の前方向） | Lp × U |
| Ut（体幹の上方向） | 股関節中点→肩中点 を正規化 |
| Lt（胸郭の左方向） | 右肩→左肩 を Ut に直交化して正規化 |
| Ft（胸郭の前方向） | Lt × Ut |

## 各角度

| 角度 | 基準姿勢（0°） | 定義・計算 | 符号 | REBA での扱い |
|---|---|---|---|---|
| 体幹の傾き | 直立 | 体幹ベクトル T（股関節中点→肩中点）を矢状面（U と Fp の張る面）で見た角度: atan2(T·Fp, T·U) | 前傾 +／後傾 − | 体幹の位置区分（自動）。**腰椎の角度ではない** |
| 体幹の側屈（参考） | 直立 | atan2(T·Lp, T·U) | 左 +／右 − | ねじれ・側屈の参考提示のみ |
| 肩と骨盤の向きの差（参考） | 0° | 肩の線と骨盤の線を水平面へ投影し、鉛直軸まわりの角度差 | — | ねじれの参考提示のみ |
| 頭頸部の傾き（参考） | 耳が肩の真上 | H = 肩中点→耳中点。atan2(H·Ft, H·Ut)（体幹に対する相対角） | 前傾 +／後傾 − | 頸部は **評価者が選択**。推定値は参考提示のみ。**頸椎の角度ではない** |
| 上腕挙上角 | 腕を体側に下ろした位置 | 上腕ベクトル A（肩→肘）と体幹の下向き軸 −Ut のなす3D角（0〜180°） | — | 上腕の位置区分（自動） |
| 上腕の伸展判定 | — | A·Ft < 0 かつ 後方成分 > 外側成分 のとき「伸展」として扱う | — | 伸展 20°超は 2点 |
| 上腕の矢状面角（参考） | 体側 | atan2(A·Ft, A·(−Ut)) | 屈曲 +／伸展 − | 表示のみ |
| 上腕の外転（参考） | 体側 | atan2(A·外側, A·(−Ut))（外側 = 左腕は Lt、右腕は −Lt） | 外転 + | 「外転・回旋」の参考提示のみ（30°超で提案）。回旋は推定しない |
| 肘の屈曲 | 肘を伸ばした位置 | 上腕ベクトル（肩→肘）と前腕ベクトル（肘→手首）のなす角。= 180° − 肩・肘・手首の3点角 | 屈曲 + | 前腕の区分（自動） |
| 手首の曲がり（参考） | 前腕と手が一直線 | 前腕ベクトル（肘→手首）と手のベクトル（手首→人差し指・小指の中点）のなす角 | 屈曲・伸展・偏位を区別しない | 手首は **評価者が選択**。推定値は参考提示のみ |
| 膝の屈曲 | 膝を伸ばした位置 | 大腿ベクトル（股関節→膝）と下腿ベクトル（膝→足首）のなす角 | 屈曲 + | 膝の補正（自動。左右の大きい方） |
| 足関節（追加情報） | 下腿に対して足部が直角 | 90° −（下腿上向きベクトル と かかと→つま先 のなす角） | 背屈 +／底屈 − | **REBA の採点には使わない** |

## 単純な3点角度との違い

- 肘・膝は関節を挟む2つの体節のなす角（3点角の補角）で、REBA の「屈曲角」にそのまま対応する。
- 体幹は「股関節・肩・鉛直」の角度で、REBA が求める「体幹の前屈角（鉛直からの傾き）」に対応させている。骨盤の傾きや脊柱の弯曲は区別できない。
- 上腕は「体幹に対する」角度（体幹が前屈していても腕を体側に下ろしていれば小さい）。REBA の上腕の定義（体幹に対する上腕の位置）に合わせている。
- 頸部・手首・ねじれ・肩の挙上は、ランドマークの位置関係だけでは REBA が求める姿勢を判定できないため、自動採点しない。

## 撮影方向の目安

骨盤・肩の左右軸が奥行き方向にどれだけ向いているかで「側方／斜め／正面・背面」を表示する。体幹・上腕の前後の角度は、側方（真横）から撮影したほうが推定が安定しやすい（正面・背面では前後方向が奥行きの推定に依存するため）。

## 既知の限界

- 単眼カメラの奥行き推定は誤差が大きく、正面・背面からの撮影や体の一部が隠れる場面では角度が不安定になる。
- カメラの傾き（ロール・ピッチ）を補正していない。
- 作業服・保護具・工具・資材による遮蔽、逆光、暗所、遠距離で推定が乱れる。
- 推定角度の精度（実測との誤差）は検証していない。
