## 採点の流れ（`src/lib/reba/scoring.ts`）

```
グループA: 体幹 + 頸部 + 脚 → Table A → + 重量/力 = スコアA
グループB: 上腕 + 前腕 + 手首 → Table B → + 把持  = スコアB
Table C(スコアA, スコアB) + 活動スコア = REBA スコア（1〜15）
```

## リスク区分（Action level）

| REBA | リスク | AL | 対応（詳細な評価を含む） |
|---|---|---|---|
| 1 | 無視できる（Negligible） | 0 | 不要 |
| 2–3 | 低い（Low） | 1 | 必要な場合がある |
| 4–7 | 中程度（Medium） | 2 | 必要 |
| 8–10 | 高い（High） | 3 | 早期に必要 |
| 11–15 | 非常に高い（Very high） | 4 | 直ちに必要 |

## 本アプリの実装上の取り決め（原著に数値・記載がないもの）

1. **区分の境界値**: 原著は「0–20°」「20–60°」のように境界が両側に現れるため、境界値は **低い方の区分** に含める（例: 体幹 20° → 2点、60° → 3点、上腕 45° → 2点、肘 60°・100° → 1点、膝 30°・60° → +1、手首 15° → 1点）。
2. **体幹の「直立」**: 原著は許容幅を定めていない。推定誤差で直立が「0–20°」と判定されるのを避けるため、初期値 **±5° を直立** とする（詳細設定で 0° / ±5° / ±10°）。
3. **上腕スコアの下限**: 支持（−1）で 0 以下になる場合は 1 とする（Table B の範囲）。
4. **膝**: 左右の膝のうち **屈曲が大きい方** で判定。片側しか推定できない場合は自動設定せず、評価者に確認を求める。
5. **評価側**: 上腕・前腕・手首（グループB）は評価側（作業者本人の左または右）の値。体幹・頸部・脚・重量・把持・活動は左右共通。評価側を変えると、左右別の手動入力はリセットする。
6. **把持** は左右共通の1項目として扱う。

## 未確認項目と仮評価

- 自動推定値も評価者の入力も無い項目は **未確認**。0点や「なし」とはみなさない。
- 未確認がある場合、その項目が取りうる全選択肢を考慮した **REBA の最小〜最大** を「仮評価」として表示する。
  - 部位ごとに未確認項目の組み合わせを列挙して部位スコアの最小・最大を求め、Table A/B/C に通す。
  - Table A/B/C が各軸で単調非減少であることを単体テストで確認している（範囲計算の前提）。
- **確定（最終点数）の条件**: 全項目が確認済み かつ 評価者が「推定された姿勢を画像で確認した」にチェック。
- 保存データ・CSV では自動推定値（auto）と評価者の入力値（manual）を別々に保持し、出所を「自動推定／手動入力／手動修正／未確認」で示す。
